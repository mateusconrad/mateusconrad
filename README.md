## Projetos em destaque

**[FanPilot](https://github.com/mateusconrad/FanPilot)**: monitor de temperatura e controle de fans do PC pelo celular. Um painel web servido pelo próprio PC mostra temperaturas de CPU, placa-mãe e GPU com gráficos históricos e tem um editor de curvas de fan. O celular acessa pela rede local depois de parear com um QR code. Feito em C# / .NET, roda no Windows e tem suporte a Linux em testes.
